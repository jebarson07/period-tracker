# Luna Tracker Feature Specifications 🌟

## 1. Luna Care Wellness Dashboard
- **Hero Banner**: *"Take care of yourself 💕"* with cartoon female illustration.
- **Diet & Nutrition**: Food & nutrition guidance for menstrual phases.
- **Pain Relief Yoga**: Guided gentle yoga poses (established visual character identity with Butterfly Pose).
- **Daily Care Tips**: Habits, thermal compresses, teas, and rest guidance.
- **Learn About Periods**: Menstrual health education & body awareness.
- **Today's Care Tip**: Daily tip card with sleeping mascot cat illustration.

## 2. Cycle Intelligence Engine
- **Rolling 6-Cycle Average**: Computes average cycle lengths from actual period start dates.
- **Delayed Cycle Detection**: Flags delayed cycles without inventing fake dates.
- **Prediction Isolation**: Predictions strictly project future dates and never alter historical stats.

## 3. Period Calendar & Logging
- Monthly grid with indicators (Period 💧, Predicted 🌙, Fertile 💚, Ovulation ⭐, Today ♡).
- Actual period logging with start date, end date, and flow intensity.

## 4. Notifications
- Native Android notification channel with custom language & personality tones.
