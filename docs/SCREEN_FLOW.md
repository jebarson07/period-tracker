# Luna Tracker Screen Flow 📱

## Onboarding Sequence (Steps 1–5)
1. **Welcome Screen** (`WelcomeScreen`) -> Animated intro and branding.
2. **Name Screen** (`NameScreen`) -> Name input.
3. **Cycle Setup Screen** (`CycleSetupScreen`) -> Last period start date.
4. **Cycle Length & Duration Screen** (`CycleLengthDurationScreen`) -> Average cycle length & duration.
5. **Notification Preferences Screen** (`NotificationPreferencesScreen`) -> Language, tone, times & discreet notifications.

## Main Application Hub (5 Navigation Tabs)
- **Tab 0: Home Dashboard** (`HomeScreen`) — Interactive cycle wheel & compact weekly calendar.
- **Tab 1: Period Calendar** (`PeriodCalendarScreen`) — Monthly grid, color-coded indicators, Log Period flow, and cycle statistics.
- **Tab 2: Luna Care Home** (`CareHomeScreen`) — Wellness dashboard featuring Diet & Nutrition, Pain Relief Yoga, Daily Care Tips, and Period Education.
- **Tab 3: Relax** — Audio relaxation & breathing exercises (Placeholder).
- **Tab 4: Profile** — User settings & cycle stats (Placeholder).
