# Luna Tracker Design System 🌸

## Core Principles
- **Comfort over Anxiety**: Pastel palettes, soft shadows, rounded surfaces (radii 24–34px).
- **Relatable & Supportive**: Cartoon 2D female illustrations and friendly typography.
- **Consistency**: Centralized colors in `AppColors` and theme settings in `AppTheme`.

## Color Palette
- **Background**: `Color(0xFFF8E8F0)` (Pastel Pink)
- **Primary**: `Color(0xFF98577F)` (Deep Plum / Pink Accent)
- **Secondary**: `Color(0xFFE9DDF9)` (Soft Lavender)
- **Period Day Highlight**: `Color(0xFFF4A6C6)` (Solid Soft Pink)
- **Fertile Window**: `Color(0xFFE2F3E6)` (Soft Sage Green)
- **Ovulation Day**: `Color(0xFFFFF8E1)` (Pastel Gold/Yellow with Star)
- **Card Tints**: Soft Pink (`#FFF0F5`), Soft Lavender (`#F3E8FA`), Soft Peach (`#FFF2E6`).

## Component Guidelines
- **Hero Banner**: Gradient cards with 28px rounded corners and 2D custom vector illustrations.
- **Feature Cards**: 2-column grid with icon badge top-right, illustration center, title, subtitle, and pill action button (`Explore →`).
- **Bottom Navigation**: Floating 5-tab pill container (`Home`, `Calendar`, `Care`, `Relax`, `Profile`).
